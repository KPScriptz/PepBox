System requirements

  • macOS 14+Sonoma or later
  • Any MacNotch or not. Non-notch Macs and external displays get a floating pill.
  • FreeNo account needed

First launch

  1. Open the DMGDownload PepBox from the latest release and double-click the .dmg file.
  2. Drag PepBox to ApplicationsDrop the PepBox icon onto the Applications folder in the window that opens.
  3. Open PepBoxLaunch it from Applications or Spotlight. Its icon appears in the menu bar, and a short welcome walks you through the basics.
  4. Grant AccessibilityOpen System Settings → Privacy & Security → Accessibility and turn on PepBox.

Why Accessibility? macOS requires it for an app to paste into other apps, listen for global keyboard shortcuts like ⌥Space, and move or resize windows (Window Snap). PepBox does not use it for anything else.

Optional permissions

macOS asks for these the first time you use a feature that needs them. You can say no and the rest of PepBox keeps working.

PermissionUsed for
CalendarUp Next shows your next meetings; Quick Search can add events.
Local NetworkLocalSend finds and sends to devices on your Wi-Fi.
Screen RecordingNot needed for Grab Text. You can leave it off.

Troubleshooting

“PepBox can’t be opened”

In Finder, right-click (or Control-click) PepBox in Applications and choose Open, then confirm. You only need to do this once. If macOS still blocks it, open System Settings → Privacy & Security and click Open Anyway.

A keyboard shortcut does nothing

Another app may already use it. Change the shortcut in PepBox's settings, or turn it off in the other app. Also check that Accessibility is still on for PepBox, since macOS sometimes turns it off after an update; toggle it off and on again if needed.

Something is stuck or behaving oddly

Open PepBox Settings → About → Hard Reset. It resets all settings and restarts PepBox; you can choose to keep your clipboard history. If the problem stays, open an issue on GitHub.
